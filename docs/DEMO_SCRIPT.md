## Recording checklist

- Record at 1080p or higher with VS Code zoom suitable for mobile playback.
- Use the current public release candidate and identify historical screenshots if inserted.
- Never show Codex or Telegram credentials, chat IDs, private messages, source code, or local profile paths.
- Do not claim monitoring of private conversations owned by the official Codex VS Code extension.
- End with `github.com/Aissarak8/agentpilot` and the words “Public pre-release.”
